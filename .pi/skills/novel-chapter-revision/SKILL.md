# Novel Chapter Revision — 章节工艺核验 Skill

**版本**：v1.2（最后更新：2026-07-01）

## 一、Skill 的核心铁律

> 这份 Skill 是从《心魔界》第 1-16 章累积修订经验中提炼的。
> **每一条铁律都来自人类用户的真实驳回与确认**，不是凭空总结。

### 1.1 三条不可违背

1. **AI 只做核验和修改建议，不直接改写文件**
   - 未获用户对每条建议的明确裁决之前，禁止动 `chapter-XX.md`
   - 一次性给出全部建议，等用户逐条 ✅/❌/✏️ 裁决，再统一落盘

2. **格式必须是"原文 / 建议改为 / 修改理由" 三段**
   - 不能用"总结/汇报"格式（已被用户驳回多次）
   - 不能只列"问题清单"而不给具体改法
   - 不能机械列标点错误和大纲对齐，必须是真正的工艺问题

3. **必须按场景/段落顺序逐段过**
   - 不能跳跃式只挑大问题
   - 一章 2000-3000 字通常会产出 15-25 条建议
   - 每个场景至少 4-8 条

### 1.2 输出格式模板（严格遵守）

```markdown
# 第X章 工艺核验单

> 核验依据：USER-REVISION-LEARNINGS vX.X + chapter-hooks-ledger
> 本章字数：约 XXXX

## 场景一·XXX（行号或起止标识）

### P-XX-01·一句话标题（说清问题本质）

**原文**：
```
[原文逐字粘贴，可带上下文]
```

**问题**：
- [问题1：具体到字句，不能笼统说"不够好"]
- [问题2]
- [问题3]

**建议改为**：
```
[完整可直接替换的改写文本]
```

**理由**：
- [为什么这么改 — 必须对应到工艺规则或人设/逻辑]
- [对长线伏笔/钩子/人设的影响]
- [呼应哪条历史修正（R-XX）或哪条工艺规则]
```

每章结尾必须给出：


## 二、核验前必做的上下文加载

进入本 Skill 时按顺序加载（如已加载则跳过）：

```
1. workspaces/{current}/USER-REVISION-LEARNINGS.md  → 经验库主文档
2. workspaces/{current}/chapter-hooks-ledger.md      → 钩子总表
3. workspaces/{current}/series/full-outline-vX.X.md  → 大纲（仅作为对齐参考）
4. workspaces/{current}/chapters/chapter-{N-1}.md    → 前章正文（保证衔接连续性）
5. workspaces/{current}/chapters/chapter-{N}.md      → 本章正文（如已落盘）
6. workspaces/{current}/characters/*.md              → 出场角色档案（人设核验依据）
```

**未加载经验库就开始核验 = 教训 D（大纲核验前置）的反向违规**。

如果用户直接粘贴正文（未落盘），仍需先读经验库+前章正文，再做核验。

## 三、工艺核验的 22 类常见问题（按场景分布）

> 以下分类来自第 10-13 章核验单的完整问题归纳。
> 实战中按场景顺序扫描，每个场景平均触发 4-8 条。

### 3.1 开篇段问题（A 类）

| 代号 | 模式 | 检查点 |
|------|------|--------|
| A-1 | 长句一逗到底，无句号断句 | 整段超过 50 字不分句 |
| A-2 | 主角自吹型内心独白 | "难道自己是天才/真不愧是" |
| A-3 | 设定/技术总结段 AI 腔 | "经过一夜的融合/看似凶险但是非常安全" |
| A-4 | 开篇陈词比喻 | "压在头顶的那座大山消失" — **v1.1边界**：若比喻与角色阶层/经历锁定（"几年"→债务时间线 / "山"→贫困），可保；仅浮空无锚点的陈词才删 |
| A-5 | 开篇主角心理直白 | 直接告诉读者"他感到轻松/紧张" |

### 3.2 人物对话问题（B 类）

| 代号 | 模式 | 检查点 |
|------|------|--------|
| B-1 | 角色语感跳脱 | 角色突然用陌生方言/口头禅 |
| B-2 | 长辈口吻错位 | 同辈角色用"你还年轻"等说教语 |
| B-3 | 配角起哄人设崩坏 | 冷静角色突然变话痨 |
| B-4 | 语气助词错位 | "哈"、"啦"等无差别堆砌 |
| B-5 | 独白过长情感过满 | 一段独白 > 60 字且情感外露 |
| B-6 | 师徒推理跳得过大 | 学生只负责"沉默"和反问 |
| B-7 | 设定灌输型台词 | 角色一口气说三组境界数据 |

### 3.3 情节铺垫问题（C 类）

| 代号 | 模式 | 检查点 |
|------|------|--------|
| C-1 | 伏笔铺垫无指向 | 角色"紧张"但不指向具体怀疑 |
| C-2 | 解谜过早 | 主角直接说出读者本该自悟的信息 |
| C-3 | 视觉锚点缺失 | "他看了一眼父亲的膝盖" 但前文没有"膝盖异常"的视觉描写 |
| C-4 | 时空逻辑断裂 | 主角突然出现在不可能在场的位置 |
| C-5 | 数据/设定前后冲突 | 上章 1250 积分 = 12.5 万，本章 2000 积分 = 20 万 |
| C-6 | 情节回旋 | 上章已交代的事，本章重新交代一遍 |

### 3.4 情绪节奏问题（D 类）

| 代号 | 模式 | 检查点 |
|------|------|--------|
| D-1 | 前后情绪矛盾 | "心一紧"立刻"安定几分" |
| D-2 | 抒情过载（双感叹号紧贴） | "好啊！这么多年终于！" |
| D-3 | 三连催泪 | "眼睛湿了+眼角发热+长大了" |
| D-4 | 感叹号超标 | 单段 ≥2 感叹号、全章 >1/200 字 — **v1.1边界**：台词中"爸，你想哪去了！"（亲子对话）和"那你也要记得还给人家！"（父亲叮嘱）有角色口吻功能，不机械计次；叙事/旁白中的感叹号仍需严控 |
| D-5 | 主角动机切换过快 | 刚悬念→立刻另一个目标 |
| D-6 | 情绪外露过满 | "心爱女孩哭得如此伤心" 这种直白词 |
| D-7 | 章末收得太干 | "躺下去" 无余韵 |
| D-8 | 章末过爆 | "实力！" 配感叹号配嘶吼 |

### 3.5 AI 腔/陈词问题（E 类）

| 代号 | 模式 | 检查点 |
|------|------|--------|
| E-1 | "涌起一股~感" | 涌起、一股、一阵、一缕 |
| E-2 | "不由得/不由的" | 病句还是陈词都禁用 |
| E-3 | 比喻堆叠 | 同段 ≥2 比喻、≥3 形容词并列 |
| E-4 | "缓缓/慢慢/静静" | 滥用副词 |
| E-5 | 训练蒙太奇旁白 | "日夜苦练水磨工夫修炼一日千里" |
| E-6 | 作者代入式审美评价 | "优雅与朴实结合却异常和谐" |
| E-7 | 网文低龄向用语 | "心爱女孩/这妖精竟然脸红了" |
| E-8 | 直接命名情绪 | "他感到愤怒/担忧/欣慰" — **v1.1边界**：长辈情绪通过主角第三人称POV观察（"眼神中出现了一抹担忧"）属于亲情合法性，不标E-8；主角命名自身情绪仍标 |
| E-9 | 总结过门 | "随后，又担忧道" |
| E-10 | 形容词堆砌 | "沉郁、戒备、亘古不变、凶性" 四词一并 |

### 3.6 道具/伏笔/钩子问题（F 类）

| 代号 | 模式 | 检查点 |
|------|------|--------|
| F-1 | 道具余韵未跨段回扣 | 手表只在父亲段出现一次 |
| F-2 | 跨章道具承重失败 | 上章已埋伏笔，本章未回扣 |
| F-3 | 暗钩被旁白剧透 | 用作者旁白说出 "他在为XX训练" |
| F-4 | 钩子被主角自信稀释 | "异常顺利" 钩子夹在"我快要掌控"内心戏中 — **v1.1修正**：身份谜题型中主角"这得有多大能量"等疑问是钩子载体（主角不知道→读者也想知道），不是钩子稀释。区分：主角下结论式的自信 ❌ vs 主角真实的困惑 ✅ |
| F-5 | 主题词预埋过早消耗 | "孤独" 在前段已暗示，章末爆点失效 |
| F-6 | 单字主题段被前后稀释 | "孤独。" 独立成段但前面已铺垫太满 |

### 3.7 爽点/言情段问题（G 类）

| 代号 | 模式 | 检查点 |
|------|------|--------|
| G-1 | 爽点后内心独白注水 | "他不知道。但他记下了" 连续5段 — **v1.1修正**："他不知道。但他记下了" 若只是认知标记（cognitive marker），不算注水；注水特指主角反复自我感动/下结论的多段独白 |
| G-2 | 爽点夸张表演损格调 | "扇耳光扇红肿" 用于正规集团下属 |
| G-3 | 主角降智迎合爆点 | "本能张口咬叉子" |
| G-4 | 言情段女主脸红无视觉起点 | "脸热热的/脸颊通红" 直白说红 |
| G-5 | 言情段同性配角起哄 | 冷静配角说"妖精脸红了竖大拇指" |
| G-6 | 主角醒悟过快 | 物理动作刚结束立刻提问"我做错了什么" |
| G-7 | 物理道具承重不足 | 言情段没让吸管/酒杯/筷子等物理道具承载紧张 |
| G-8 | 配角无功能性沉默兜底 | 高情商配角不"嘘"压制起哄 |

## 四、22 类问题的"建议改为" 标准工艺

### 4.1 用动作环境替代抒情（治 D-2/D-3/D-6/E-8）

**反面**：
```
听着听着，眼睛慢慢就湿了。
眼角竟有点发热。
"儿子，长大了！"
```

**正面**：
```
李强没说话。
他低着头，手放在膝盖上。
过了很久。
"……儿子。"
声音有点哑。
"长大了。"
李一凡看着父亲花白的鬓角，没说话。
```

**工艺规则**：
- 删掉所有"眼睛湿了/眼角发热/心头一暖"
- 用"低头/手放膝盖/声音哑/花白鬓角"等具体动作描写
- 哽咽用 **"……儿子。" + 停顿 + "长大了。"** 拆句呈现
- 句号代替感叹号

### 4.2 信息差留白（治 C-2/F-3/F-4）

> **v1.1 重要修正**：P-12-06 用户驳回后修订 — 身份谜题型钩子中主角的内心质疑是钩子载体，不是信息差违规。
> 核心边界：主角"替读者下结论" ❌ ≠ 主角"属于角色本人的真实疑惑" ✅

**反面**（主角算完账帮读者做结论）：
```
1250 积分 = 12.5 万，2000 积分 = 20 万。
按照这个速度，再有三个月就能——
李一凡在心里算了一遍。
结论很明确：用不了多久了。
```

**正面**（信息差·主角只观察事实）：
```
张大强，大强集团董事长。
市值数十亿。
这就是自己贷款的那家公司。
陈少，陈队。
这两个字在他心里来回过了一遍。
```

**正面·身份谜题型**（主角真实内心质疑 = 钩子载体，合法）：
```
这得有多大能量，才能让数十亿公司的董事长屈尊来讨好自己这个穷小子。
队长对所有队员都是这么提供帮助的吗？还是只有自己？
他不知道。
但他记下了。
```

**工艺规则**：
- 删掉主角"替读者算账/总结/下结论" 的旁白思维
- **但保留主角"角色本人的真实认知过程"**：
  - "队长对所有队员都是这么吗？还是只有自己？" — 这是主角的合理怀疑，是 HOOK-9 钩子载体
  - "他不知道。但他记下了。" — 认知标记（cognitive marker），为后续回扣埋锚点，不是替读者写答案
- **边界判定三问**：① 主角是在替读者说话（旁白思维）还是在问自己心里的话？② 这段内心戏删除后，读者是否还能自己推导出相同信息？③ 这段内心戏是角色认知成长的必要一步吗？
- 信息差（主角不知道=读者不知道）与 内心标记（主角记住了=读者也跟着标记）是两种完全不同的工艺

### 4.3 物理道具递进表达紧张（治 G-7）

**反面**：
```
白小柔吸管中的果汁回落到杯中。
```

**正面**（吸管四段递进）：
```
开场：插到杯底咕咕搅动（紧张讨论）
中段：吸管停了（听到关键情报）
爆点：彻底从嘴里掉了出来，撞在杯沿上发出一声轻响
压制：把没说完的话咽了回去，重新含住吸管
```

**工艺规则**：
- 一个物理道具用 3-4 段递进表达情绪升级
- 比角色心理描写有力 100 倍

### 4.4 三段递进救主角智商（治 G-3）

**反面**：
```
李一凡愣了愣，本能的张口咬住叉子。
```

**正面**：
```
李一凡愣了一下。
下意识抬手要接。
可叉子已经送到嘴边了。
他鬼使神差地张口，把那块肉接了过去。
```

**工艺规则**：
- 第一段：正确反应受阻（伸手接）
- 第二段：时空错位（叉子已到嘴边）
- 第三段：冲动失控（鬼使神差）
- **保留爆点的同时保住主角智商**

### 4.5 师徒对话有呼吸（治 B-6/B-7）

**反面**（设定灌输型）：
```
"炼体7大阶段，你才第一阶筑体境小成。炼魂7大境界，你也是第一境灵觉境。空间异能虽是S级，但也才开发到百分之三十……"
```

**正面**（拆段+反问+留白）：
```
"小家伙，你现在筑体小成。"
"灵觉初境。"
"空间异能 S 级，开发三成。"
墨老顿了顿。
"这个进度，已经吓死人了。"
"但还不够。"
```

**工艺规则**：
- 数字保留但拆成短句
- 加 "顿了顿" 给师徒呼吸感
- 师傅先肯定再否定，**"已经吓死人了，但还不够"** 是导师标配节奏

### 4.6 章末三重余韵（治 D-7/F-1）

> **v1.1 修正**：三重余韵是**可选项**，不是铁律。用户在第12章驳回此建议，选择用"跨章悬念前置"替代余韵闭合。

**反面**：
```
李一凡把鳞片放回盒子里，仰面躺下去。
```

**正面·余韵闭合型**（手表三回扣）：
```
"知道了。"
李一凡把鳞片放回盒子里。
盖上。
仰面躺下去。
天花板很白。
隔壁房间，父亲翻身的声音。
更远处。
旧手表的滴答声，还在响。
```

**正面·跨章悬念前置型**（灰白光罩无名登场）：
```
一股波动扫过，在鳞片空间中涌起无数乱流。
一层灰白色的薄膜闪了一下。
李一凡没有受到丝毫影响。

李一凡欢喜地将鳞片再次拿起，放在眉心，继续感受，融入。
一夜就这么过去。
```

**工艺规则**：
- 章末**优先服务下一章钩子**，其次服务情绪闭合
- 两种合法路径：① 回扣前面场景道具做余韵收束（温情向）；② 前置下一章的悬念种子做张力延续（悬念向）
- **用户偏好判断**：当章末同时存在"情感余韵候选"和"悬念推进候选"时，优先保留悬念推进
- 不要机械套用"必须三回扣"铁律 — 优先看本章的钩子总表指定兑现目标

### 4.7 言情爆点·配角沉默兜底（治 G-5/G-8）

**反面**：
```
"一凡，了不起，这妖精竟然脸红了！"苏晴给李一凡竖起大拇指。
```

**正面**：
```
苏晴看了他一眼，没说话。
白小柔小声开口："一凡哥……"
"嘘——"苏晴打断她。
苏晴慢慢端起酒，喝了一口。
"没事。"
"多吃点。"
她把整盘排骨推到了李一凡面前。
```

**工艺规则**：
- 高情商配角用沉默替主角兜底
- "嘘——" 压制其他配角的好奇
- 用 "多吃点 + 推排骨" 这种动作表达姐妹情，**不开口起哄**

### 4.9 信息差·主角反问→NPC揭示式（治 C-2 信息复习不当）

> **v1.1 新增**：P-12-04 用户独创工艺 — 当需要"复习"已交代信息时，让主角假装不知道主动提问，由NPC对话回应。

**反面**（旁白注解式复习）：
```
"陈少，也就是你们陈队，昨天找过我们集团大老板。"
```

**正面**（主角反问→NPC揭示式）：
```
"陈少，昨天找过我们集团大老板。"
"这债已经清了。"

"陈少？"
李一凡印象中，并不认识姓陈的少爷。

"陈少，就是你们陈队！"
```

**工艺规则**：
- 信息复习 = 让角色"不知情"提问，而非作者旁白插注
- 主角反问是戏剧节点，旁白注解是信息堆砌
- "也就是你们陈队" 是怕忘了的AI思维；"陈少？→ 陈少，就是你们陈队！" 是对话节奏
- 适用于任何"读者已知但角色未知"或"读者可能遗忘但不宜旁白提示"的信息点

### 4.10 跨章伏笔前置·先种子后命名（治 F-1/F-2 道具承重衔接）

> **v1.1 新增**：P-12-22 用户驳回章末三回扣后独创 — 在章节N埋下无名现象，章节N+1正式命名+提问。

**工艺模板**：
```
（第12章·无名登场）

一层灰白色的薄膜闪了一下。
李一凡没有受到丝毫影响。
——读者注意到的只是"安全得过分"的感觉

（第13章·命名+提问）

"他想不明白。但这话他没问出口。"
——读者回看第12章，发现种子早已埋下
```

**工艺规则**：
- 第N章：现象出现 + 主角未深究（"没有受到丝毫影响"）
- 第N+1章：读者/主角注意到反常 + 提出问题但暂不解答

- 命名阶段才给术语（"灰白光罩"），仍不解释来源

**工艺规则**：
- 从"那个东西"到"还挺讲原则"的渐变是关系弧线的合法推进
- 梦魇不解释、主角不追问 = 关系留白保持；主角评价但不追问 = 关系温度上升但不越界

## 八、特别注意事项（高频踩坑）

### 8.1 工具使用规则

- `write` / `edit` 必须显式传 `path` 参数（多次因为漏写 path 导致校验失败）
- 一次性多处修改用 **一次 `edit` + 多个 edits[]** ，不要分多次调用
- bash heredoc 用 `<< 'EOF'` 避免 unicode 转义被 bash 解释
- `cat >> file << 'EOF'` 比 write 更适合给已有文件追加大块内容

### 8.2 Windows 编码

- Python 输出中文必须先 `sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')`
- 否则 GBK 终端显示乱码（但文件内容是正确的）
- 不要被乱码骗到去"修复" 实际正确的文件

### 8.3 备注块扫描误报

错字扫描必须只对正文做：
```python
body = full.split('## 本章创作备注')[0]
# 或
body = full.split('<!-- 创作备注')[0]
```

否则备注里的"错字修复留痕"块会触发自匹配，产生误报。

### 8.4 大纲核验前置（教训 D）

**核验前必读最新版大纲**。归因分三层：
- 大纲规划落地（不是独创）
- 半规划半独创（分层记录）
- 纯用户独创（建议回写大纲）

未读大纲就开始核验 = 工艺事故。

- ❌ 不要把"大纲位置偏移"当工艺问题
- ❌ 不要直接调用 `novel_narrator` / `novel_critic`（这是 `novel_generate_chapter` 内部工具）

### 8.6 信息差留白的边界 — 禁止一刀切

**P-12-06 教训**：我建议删除"这得有多大能量……他不知道。但他记下了。"整段，被用户驳回。

**错误逻辑链**：主角说出对局面的判断 = 替读者下结论 → 必须删除

**正确边界判定三问**：
1. 主角是在替读者说话（旁白思维），还是在问自己心里的话？
   - "队长对所有队员都是这么吗？还是只有自己？" → 角色本人的真实困惑 ✅
   - "1250积分=12.5万，按这个速度三个月就能……" → AI帮读者算账 ❌
2. 删除后，读者还能自己推导出相同信息吗？
   - 能 → 可删；不能 → 必须保留
3. 这段内心戏是角色认知成长的必要一步吗？
   - "他不知道。但他记下了。" → 认知标记，为后续回扣埋锚点 ✅
   - "头顶那座压了几年的山没了" → 有"几年"债务时间线锁定，非浮空比喻 ✅

### 8.7 陈词比喻的阶层语言适配

**P-12-07 驳回**："头顶那座压了几年的山没了" 被我标 A-4，用户驳回。

**错误逻辑**：任何比喻 = 陈词

**正确判定**：
- "压了几年的山" → "几年"回扣第1/9章债务时间线，"山"回扣贫困设定 → **有具体落点的比喻是合法的角色语言**
- 只删**浮空的**陈词：如"心里像打翻了五味瓶"（无锁定到具体角色经历的通用模板）

### 8.8 长辈情绪注解的第三人称POV豁免

**P-12-09 驳回**："眼神中没有李一凡期待的那种笑容，反而出现了一抹担忧" 被我标 E-8，用户驳回。

**错误逻辑**：命名长辈情绪 = AI腔

**正确边界**：
- 主角命名**自己的**情绪 → E-8 违规
- 主角通过第三人称观察**长辈的**情绪 → 亲情线的合法情感锚点
- "李一凡期待的那种笑容" 说明这是主角的主观视角过滤，不是全知旁白
- "一抹担忧" 中的"一抹" 虽是AI腔候选词，但在第三人称主观观察中可豁免（与 §4 的"涌起一股"不同，那不是角色POV）

### 8.9 半句话省略号的未知关系钩 — 先问后删

**P-12-14 驳回**："那她后悔..."被我当错字建议删除，用户驳回。"她"是用户独创的前女友伏笔。

**工艺规则**：
- 遇到指代不明的代词（"她"/"那个人"/"那件事"），**先判断是否为故意埋设的未知关系钩**
- 若是伏笔：保留 + 提示"此处'她'应在后续2-3章内给到至少一个线索"
- 若确认是错字：才标错字
- **禁止**：未问用户就直接建议删除

**判定信号**：
- 出现在主角许愿/展望未来段（如"以后我还要……"）→ 大概率是伏笔
- 出现在日常叙述中无上下文 → 可能是错字

### 8.10 物理实体列举的用户排版习惯

用户倾向使用 **换行+逗号** 排版（而非句号独立）：
```
破墙，
旧桌，
掉漆的椅子。
```

不要在核验时强推"句号独立成段"格式。两种格式功能等价，用户偏好即项目规范。

### 8.11 章末结尾的用户偏好优先级

**P-12-22 驳回**：我建议"手表三次回扣+父亲翻身"的余韵闭合，用户改成"灰白光罩无名登场"的悬念前置。

**优先级（从高到低）**：
1. 本章钩子总表的**指定兑现目标**（HOOK-12-3 孤独主题预埋已在P-12-21完成）
2. **下一章的悬念种子**（灰白光罩→ch13异常护持）
3. 情绪余韵闭合（手表回扣）

章末不是情感安放处，是**阅读动力的接力点**。

### 8.12 章纲对用户重写侧的层级（v1.2 新增·修正 73）

**Ch16 教训**：AI 核验单以章纲（ch16-outline-explicit.md）不匹配为由给了 4 条阻断级 CONTRACT 违反。用户手动重写后全部保留偏离。

**铁律**：
- 显式章纲在阶段2触发硬门禁——但门禁是**AI系统侧**的
- 用户对已落盘章节的手动重写**不受章纲约束**
- 核验用户手改稿时，**不应以章纲不匹配为由给阻断级判定**——应以用户版本为新基线
- 用户重写后应当：① 回写大纲+世界观 ② 标记章纲"已被用户重写替代"

### 8.13 戏剧反讽 vs 全知越界（v1.2 新增·修正 74/75）

**Ch16 教训**：AI 把"主角未察觉的客观现象（波纹/果然如此）"误判为全知越界或钩子稀释。

**正确边界**：
- 全知越界 = 叙述者说出**只有作者才知道的信息**（如替角色下结论）
- 戏剧反讽 = 叙述者呈现**客观发生但主角未察觉的现象**，且明确标注"毫无察觉"
- "果然如此" ≠ 钩子稀释 —— 当主角与对方已有建立关系时，是关系确认而非轻率定性
- 信息差不仅存在于"主角不知道"vs"主角知道"，更存在于"主角以为知道"vs"读者看出来有蹊跷"

## 十一、v1.1 升级·核验单的「不可改坏」铁律

> 来自用户对 Ch13-15 最终版改稿的反推学习。
> 这些是 v1.0 阶段我**误判过的工艺方向**，必须固化为铁律。

### 11.1 六条「不可改坏」铁律

**铁律 R-NC-01·情感顶点配角不可被克制化**
- 主角和高情商配角必须克制
- 但**当前事件的情感核心承担者** 允许长独白、允许"可是，可是"重复、允许"泣不成声"
- 判定方法：问自己 "这是不是 ta 此刻最痛的事？" → 是 → 不要砍独白
- **反例**：核验 Ch13 小妖讲铁山段时建议砍 90→40 字，被用户驳回

**铁律 R-NC-02·主角内心独白不可精英化**
- 22 岁穷小子主角会用"心爱女孩"、"无能为力"这类网文常见词
- 把这些词改成更精致的表达 = **把主角变成了作者** = 人设破坏
- **反例**：Ch14 章末 "看着心爱女孩哭的如此伤心" 我建议删除，用户保留

**铁律 R-NC-03·爆点不必用句号代替感叹号**
- 爆点可以保留感叹号
- 用 **前置/后置的克制动作**（"缓缓吐出"/"低声说"/"嘶哑地"）来弱化
- 不要机械执行"句号 > 感叹号"
- **反例**：Ch14 "实力。" 句号方案被用户改回 "实力！" + "缓缓吐出两个字"

**铁律 R-NC-04·反派人味 > 反派段位一致**
- 反派的"手段段位一致性" 不是最高优先级
- **让反派具象化为有家庭的人** 优先级高于维护阵营段位统一
- 跪下、哭家人、求饶 = 反派人味，不是反派降级
- **反例**：Ch15 万老板"砸家+跪下+罪不及家人" 被我以"陈锋段位倒退" 驳回，用户保留并强化

**铁律 R-NC-05·章末不必双视角收束**
- 切到另一视角（如父亲）不是必然加分
- 单视角的物理痕迹留白（"枕头上一个浅浅的凹陷"）有时更狠
- 章末切镜头会**稀释主线悬念**
- **反例**：Ch15 末我建议"切到父亲收碗+睡了？"，用户止于主角消失的物理痕迹

**铁律 R-NC-06·数据修正建议要留权给用户**
- 积分、金额、距离、时间等**全局一致性数据** 不应在核验单里给具体数字
- 应该指出"前后冲突" 即可，**数值由用户全局校准**
- **反例**：Ch14 任务积分 1250→4000，用户最终改为 2500→4500

**铁律 R-NC-07·章纲对用户重写侧不是律法（v1.2 新增·修正 73）**
- 章纲是 AI 系统侧生成时的契约，不是用户手动重写时的律法
- 用户重写已落盘章节时，章纲降级为"参考骨架"
- 核验员不应以章纲不匹配为由给阻断级 CONTRACT 违反
- **反例**：Ch16 用户保留全部 8 项章纲偏离（噬魂兽正面出场/两兽相杀/阿巴塔空降等），AI 的 4 条阻断级 CONTRACT 违反全部驳回

**铁律 R-NC-08·"声明→执行"是 AI 惯性，"测试→执行"是人类决策（v1.2 新增·修正 79）**
- AI 写作的默认节奏：角色声明目标 → 直接执行
- 人类角色的真实节奏：轻量测试 → 评估困难 → 确认决心 → 正式执行
- 不要用"声明→执行"的 AI 惯性去"优化"用户的"测试→执行"链路
- **反例**：Ch16 用户加"先试一刀枝丫"测试段，AI 建议删掉直接进入"第1棵→咔→轰隆→收"

- 经典案例："——又是陈锋。" 之后加 "这不是陈锋的做事风格，难道是张大强。"

### 11.3 核验单的「让权」原则

基于 6 条铁律，核验单输出时必须做到：

1. **建议而非命令**：每条 P-XX 必须明确这是"建议改为"，不是"应该改为"
2. **数据留权**：积分/金额/距离类数据只指出冲突，不给具体数字
3. **情感顶点检查**：核验情感段前先问"这是不是此角色此刻最痛的事？" → 是 → 慎砍
4. **主角语言层级保护**：检查改稿是否把主角变得"作者化" → 是 → 撤回建议
5. **段位一致性 vs 人物厚度** 冲突时：人物厚度优先
6. **章末收束多方案**：不要单一推送"切镜头" 或 "单视角"，给用户两个备选
