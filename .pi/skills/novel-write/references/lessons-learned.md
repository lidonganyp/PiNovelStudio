## 一、生成问题复盘

### 问题1：场景压缩综合症

**症状**：7个独立场景挤在一章，每个只给了3-5行，人物突然出现突然消失。

**根因**：大纲将连续多章的内容写在一个段落里，AI（和人）都误以为要在一章内全部覆盖。

**规则**：
- 大纲中每个「场景X」对应一章——标题写"第N-N+2章"只是说明这些章节属于同一个叙事段落，不代表挤在一章。
- 当大纲内容超过3个独立场景时，必须拆分为多章。
- 每章只聚焦1-2个核心场景 + 1个伏笔/过渡场景。

### 问题2：人物出场无铺垫

**症状**：新配角从普通场所突然冒出来。读者不知道TA是谁、为什么出现。

**根因**：前文没有这些角色，当前章是他们的首次出场，但生成时没有给出场前摇（环境、其他人的反应、主角的回忆）。

**规则**：
- 首次出场的角色必须给出场前摇：①环境线索 ②他人反应/议论 ③主角的记忆/认知 ④实际出场。
- 配角出场顺序不能倒置——高关注度配角在正式出场前需要环境铺垫（比如之前有人议论TA、主角在公共空间路过时看到TA在人群中）。

### 问题3：情绪转折无过渡

**症状**：主角从"拘谨害羞"直接跳到"我好像很厉害"，中间缺了心理渐变。

**根因**：膨胀是一个过程，不是开关。第一次被认可就膨胀到"对手算什么"不合理——膨胀的种子应该先种下（微妙的自信心提升），再通过连续事件浇水，最后才由导师/危机介入引爆。

**规则**：
- 情绪弧线必须跨章递进，同一章内不能从A直接跳到Z。
- 膨胀递进路径：①被认可的小欣喜→②"好像我也不差"→③"他们也不过如此"→④危险的自大。每步至少间隔一个场景或时间跳跃。
- 关键情绪转折点必须用环境描写+动作细节来锚定，不能只用独白。

### 问题4：质量优先于字数

**症状**：为了卡2000-3000字，把本该写5000字的内容强行压缩。

**根因**：字数目标是约束，不是硬指标。质量不达标的3000字不如质量达标的5000字。

**规则**：
- 质量是第一指标。如果当前大纲内容需要更多字数才能保证质量，就拆分为多章。
- 单章字数弹性范围：2000-4000字。超过4000字时必须拆分。
- 任何场景如果不到200字就跳转，说明需要扩展或合并到其他章节。

### 问题5：大纲内容理解偏差

**症状**：大纲写"内心有些许膨胀"——是"些许"不是"很强"；大纲写"设计几件事情来制造爽点"——是情节设计清单，不是必须全部在当前章发生。

**根因**：把大纲的情节清单当成场景清单，忽略了"设计"二字的意图——这是给作者参考的素材，不是强制执行的剧本。

**规则**：
- 大纲中"设计几件事情来制造爽点"类描述 = 素材池，不是场景清单。从中选取1-2件放入当前章节即可。
- "预埋钩子/种子" = 只需要设置前提条件，不需要在本章引爆。钩子的存在感应该足够低，读者第一次读时几乎注意不到。
- "内心有些许膨胀"的"些许" = 主角自己都没意识到的微小变化，通过行为细节暗示，不能通过内心独白明说。

## 二、更新的生成约束规则

以下规则注入到所有后续生成的系统提示词中：

```
## 叙事节奏约束

### 场景密度
- 单章最多2个核心场景 + 1个伏笔场景
- 每个核心场景不少于500字
- 场景切换必须有过渡（时间跳跃/环境切换/人物视角切换）

### 情绪递进
- 膨胀线: 被认可→"好像也不差"→"不过如此"→危险自大（每步至少间隔一个场景）
- 感情线: 注意到了→心跳异常→开始在意→忍不住多看→第一次互动（每步至少间隔一个场景）
- 恐惧线: 隐约不安→意识到异常→确认威胁→做出反应（每步至少间隔一个场景）

### 角色出场
- 首次出场角色: ①环境线索 → ②他人反应 → ③主角认知 → ④实际出场（不要求全有，但至少有2个）
- 已出场角色再出场: 不需要重新介绍，但状态变化需要暗示

### 膨胀种子埋设规则
- 不通过内心独白明说"我膨胀了"
- 通过行为变化暗示：
  - 说话声音比平时大了一点
  - 走路时肩膀比平时挺了一点
  - 对以前会犹豫的事现在不犹豫了
  - 看人的角度变了（以前仰视的人现在平视了）
- 每次行为变化后，紧跟一个"旧的自己"闪回（如想起以前遇到这种事会怎样），形成对比

### 场景充足性检查
- 生成前检查：当前章节的目标场景数是否 > 3？如果是，拆分为多章。
- 生成后检查：是否有场景 < 200字？如果有，扩展或删除。
```

## 五、真人目的性写作与主角主动性规则

### 目的性写作

- 每句话必须有目的：推进情节、埋伏笔、体现性格、制造冲突、承载情绪转折，五者至少命中一项。
- 能一句写清楚的，不拆成两句；能删除且信息不损失的句子，必须删除。
- 描写必须服务于行动、情绪、氛围或信息变化，不能只是描写。
- 对话必须推动剧情，不能只是聊天；上下文能识别说话人时删除"某某说/某某道"。
- 情绪表达要克制，用动作替代心理描写，点到即止。

### 高风险 AI 句式

- 禁止"不是A，不是B，是C"式否定定义链。常规信息应直接写 C，以及 C 对人物行动、气氛或判断造成的影响。
- 禁止空泛机器比喻，如"指示灯/屏幕/设备像野兽眼睛/鬼火"。如果比喻不改变读者对风险、人物或信息的判断，必须删除。
- 禁止无目的流程细节，如填表、准备装备、灯光变化、声音响起等，除非它们直接推动事件。
- 禁止过度文学化，不堆砌比喻、修辞和形容词。
- 禁止重复同一场景、同一反应、同一内心独白。

### 主角主动性与成长线

- 主角不是被动失败者，是主动选择者；他有自己的思考逻辑、判断和成长。
- 禁写"身体僵硬"来表现失败。涉及能力使用时，应写成主动选择、风险控制或追求 100% 掌控。
- 战斗场景要写策略、来回、搏斗、受伤、代价和反思，不能一笔带过。
- 亲人不是工具人，看到主角异常要有真实反应；旧物、亲情、队友信任、人间烟火是对抗欲望侵蚀的锚点。
- 幕后操控不要过度解释，只暗示能力影响；导师型角色只在主角陷入欲望太深时提醒，其他时候以观察为主。
