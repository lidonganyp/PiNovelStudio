# Quad Gates 质量门控规范

> 详细说明 Critic Agent 的四维质量评分体系

## 概述

Quad Gates 是 PiNovelStudio 的核心质量保障体系，包含四个维度的评分门控。只有通过所有门控的章节才能发布。

## 四维评分体系

### Gate 1: 叙事与世界规则（硬红线）

**权重**: 最高（阻塞性）

**检查项**:

1. **硬红线检测** - 检测违反世界观硬红线的情节
   - 力量上限突破
   - 规则禁区触碰
   - 逻辑漏洞

2. **角色行为一致性** - 检测角色行为的合理性
   - 性格与行为匹配
   - 动机明确
   - 决策符合角色弧线

3. **因果链完整性** - 检测事件的因果关系
   - 事件之间逻辑连贯
   - 转折有铺垫
   - 结局有必然性

4. **世界规则遵守** - 检测世界观一致性
   - 力量体系遵循
   - 势力关系合理
   - 设定不矛盾

**通过阈值**: 0.8

**评分标准**:

| 分数 | 说明 |
|------|------|
| 0.9-1.0 | 完美，无任何问题 |
| 0.8-0.89 | 优秀，有轻微瑕疵 |
| 0.7-0.79 | 良好，有明显问题需修复 |
| 0.6-0.69 | 一般，需要重大修改 |
| < 0.6 | 失败，阻塞发布 |

**阻塞规则**: 此门控为阻塞性，低于 0.8 必须修复后重新审查。

---

### Gate 2: 追读力

**权重**: 高

**检查项**:

1. **钩子设置密度** - 每 2000 字是否有翻页钩子
   - 目标：≥ 1 个钩子/2000字
   - 评估：钩子类型、强度、位置

2. **情绪曲线起伏** - 检测情绪变化节奏
   - 目标：至少 3 种情绪
   - 评估：情绪多样性、转换自然度

3. **信息落点控制** - 检测信息释放节奏
   - 关键信息不过早揭露
   - 信息差制造阅读欲望
   - 揭秘节奏把控

4. **翻页欲望强度** - 评估读者是否想继续
   - 章末钩子强度
   - 悬念设置
   - 情绪高点收尾

**通过阈值**: 0.7

**爽点密度标准**:

| 类型 | 说明 | 密度要求 |
|------|------|----------|
| 碾压爽点 | 主角战胜对手 | ≥1/3000字 |
| 突破爽点 | 境界/实力提升 | ≥1/5000字 |
| 打脸爽点 | 反击轻视 | ≥1/4000字 |
| 揭秘爽点 | 真相揭露 | 视剧情需要 |

---

### Gate 3: 文学质量

**权重**: 中

**检查项**:

1. **语言张力** - 检测文字的感染力
   - 动词使用精准
   - 修辞恰当
   - 节奏感强

2. **五感描写** - 检测多感官体验
   - 视觉：色彩、形状、光影
   - 听觉：声音、语调、静默
   - 嗅觉：气味描写
   - 触觉：质感、温度
   - 味觉：（特定场景）

3. **对话自然度** - 检测对话的真实性
   - 不出现机械式对话
   - 角色声音有区分度
   - 潜台词丰富

4. **描写与叙述平衡** - 检测节奏把控
   - 不过度描写
   - 不干巴巴叙述
   - 动静结合

**通过阈值**: 0.7

---

### Gate 4: 风格一致性

**权重**: 中

**检查项**:

1. **指纹匹配度** - 与目标风格的相似度
   - 句式特征
   - 词汇偏好
   - 叙事节奏

2. **与已发布章节的一致性** - 检测系列一致性
   - 角色语言一致
   - 叙事风格统一
   - 世界观延续

**通过阈值**: 0.75

---

## 综合评分计算

```
overall_score = gate1 * 0.35 + gate2 * 0.30 + gate3 * 0.20 + gate4 * 0.15
```

**发布标准**:

- 所有 Gate ≥ 阈值
- overall_score ≥ 0.75

## 问题定位与修复

### 问题段落标记

Critic Agent 会对问题段落进行精确定位：

```json
{
  "problem_paragraphs": [
    {
      "paragraph_index": 5,
      "start_char": 1200,
      "end_char": 1500,
      "issue_type": "weak_dialogue",
      "severity": "warning",
      "description": "对话过于机械，建议增加潜台词",
      "suggestion": "在对话中融入角色情绪和肢体语言"
    }
  ]
}
```

### 修复优先级

1. **Critical** - 必须修复，影响发布
2. **Warning** - 建议修复，影响质量评分
3. **Info** - 可选修复，优化体验

---

## AI 腔检测（辅助评分）

AI 腔检测不作为独立 Gate，但影响所有 Gate 的评分：

| 密度 | 等级 | 影响 |
|------|------|------|
| < 0.1 | 绿色 | 无影响 |
| 0.1-0.3 | 黄色 | 轻微扣分 |
| > 0.3 | 红色 | 重大扣分，强制重写 |

---

## 修订流程

### 一轮修订

1. Critic Agent 评分
2. 定位问题段落
3. 生成修复建议
4. Narrator Agent 定向重写
5. 重新审查

### 二轮修订

如果一轮修订后仍未通过：

1. 分析失败 Gate
2. 判断是否需要结构性修改
3. 如需结构修改，返回 Architect 重新设计 DAG
4. 如仅需局部优化，继续定向重写
5. 最终审查

### 放弃条件

连续两轮修订仍未通过：
- 记录当前问题
- 提示用户人工介入
- 保存当前最佳版本
