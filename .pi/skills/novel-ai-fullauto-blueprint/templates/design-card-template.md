# 子情境设计卡模板 v1.0

> 复制到 `workspaces/{id}/series/design-card-template.md`。
> 每个事件单元（副本/案件/任务/局）进入正文前必填。
> 无设计卡阻断章节生成（config.json `ruleProofRequired: true`）。

---

## 设计卡格式

```yaml
名称: ""
编号: N-XXX
难度等级: 灰 / 蓝 / 紫 / 红 / 黑 / 白
预计章节数: 3-5

明示规则:
  - "规则原文 1（最多 5 条）"
  - "规则原文 2"

隐藏规则:
  - "隐藏规则 1（按卷一-二 1 条 / 卷三 2 条 / 卷四-五 3 条）"

死亡触发器:
  - "条件 / 表现 / 不可逆性"

正确解法:
  漏洞类型: 措辞 / 逻辑 / 触发顺序 / 反向规则
  操作步骤: |
    1. 主角发现异常
    2. 用低风险方式验证
    3. 重定义规则
    4. 利用漏洞过关
  解法证明: "为什么这个解法成立，不靠巧合不靠开挂"

装逼锚点:
  类型: B1-B6
  触发位置: 通关时 / 通关后 / 通关前
  目标观众: 队友 / 对手 / 系统 / 自言自语

打脸对象:
  类型: S1-S4
  被打脸者: 角色名称 / 群体
  打脸方式: 一句话 / 系统反馈 / 行动结果

章末钩子:
  模板: H1-H8
  内容: "钩子句"
```

## 卷一示例（D1 措辞陷阱型 / 必含此示例避免 AI 起手摸不到节奏）

```yaml
名称: "诚实的房间"
编号: N-002
难度等级: 灰
预计章节数: 3（第 2-4 章）

明示规则:
  - "房间内任何虚假陈述将触发清算。"
  - "清算只对说话者本人生效。"
  - "退出条件：房间内所有人完成一次自我陈述。"

隐藏规则:
  - "沉默也算虚假陈述（缺省默认为'我是诚实的'）。"

死亡触发器:
  条件: 任何陈述被判定为虚假
  表现: 说话者皮肤逐层透明化，30 秒内消散
  不可逆性: 不可复活，不可中止

正确解法:
  漏洞类型: 措辞
  操作步骤: |
    1. 林觉读规则，注意到"虚假陈述"的判定标准未定义
    2. 用低风险陈述测试边界："我现在说的这句话不是真的"——递归判定，规则系统短暂卡顿
    3. 林觉发现：规则只能判定"事实陈述"，不能判定"自指陈述"
    4. 通关方式：所有人说一句无可判定的自指陈述
  解法证明: 规则原文"虚假陈述"必须有真值判定，自指悖论无真值

装逼锚点:
  类型: B1
  触发位置: 通关前
  目标观众: 副本里看不起新人的老手

打脸对象:
  类型: S1
  被打脸者: 副本老手"老周"——开场嘲讽"新人乖乖等死就好"
  打脸方式: 林觉点破规则后，老周沉默，最后递了一句"碎片市场加我个微信"

章末钩子:
  模板: H4
  内容: "老周盯着林觉走出副本的背影：'这哥们是策划吧？不，是出题人吧？'"
```

## 各卷复杂度预算

| 卷 | 明示规则 | 隐藏规则 | 同时在场队友 | 副本长度 |
| --- | --- | --- | --- | --- |
| 卷一 | 2-3 | 1 | 0-1 | 3 章 |
| 卷二 | 3 | 1-2 | 1-2 | 3-4 章 |
| 卷三 | 3-4 | 2 | 1-3 | 4 章 |
| 卷四 | 4-5 | 2-3 | 0-3 | 4-5 章 |
| 卷五 | ≤ 3 | 1-3 | 关键角色 | 5 章 |

**原则**：规则不是越多越高级，清晰死锁才高级。每个事件单元只证明一种核心能力成长。复杂单元必须配失败样本（NPC 死在错误解法）。
