## 不可违背的关系规则

- {主角} ↔ {挂壁导师}：卷一-三只能"留注释"，不能正常对话
- {主角} ↔ {女主/盟友}：卷X末才正式同盟，之前只能"公对公接触"
- {主角} ↔ {大反派}：卷三才有化名对线，卷四才实名
- 任何角色对主角的态度变化必须建立在"看到主角做了一件事"上，**禁止"莫名其妙突然信任"**。

## 关系状态定义（严格枚举）

| 状态 | 定义 | 行为表现 |
| --- | --- | --- |
| **陌生** | 不认识或仅听过名字 | 无直接互动 |
| **接触** | 直接见过/对话过 | 表面客气 |
| **怀疑** | 有理由不信任对方 | 提防、试探话术 |
| **试探** | 互相评估是否可合作 | 低风险信息交换 |
| **合作** | 短期项目级合作 | 利益对等交换 |
| **同盟** | 长期/关键利益绑定 | 关键情报共享、互相托底 |
| **敌对** | 公开/隐性对立 | 直接对抗或拒绝合作 |
| **反水** | 从敌方阵营倒戈 | 提供敌方情报 |
