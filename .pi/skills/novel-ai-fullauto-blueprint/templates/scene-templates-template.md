## 一、章末钩子模板（H1-H8）

| 编号 | 类型 | 触发情境 | 模板句式 | 示例 |
| --- | --- | --- | --- | --- |
| **H1** | 装逼瞬间 | 通关后甩话 | "主语 + 动作 + 一句结论性短句" | "他把碎片扔在桌上：'下次别给我送这种入门级的。'" |
| **H2** | 反派打脸 | 反派话音未落被打脸 | "反派宣告 + 系统冷面反馈" | "L 权限账户后台：访问失败 / 0.3 秒前已被人捷足先登。" |
| **H3** | 下章预告 | 章末看到下个事件单元入口 | "环境锚点 + 倒计时 / 编号" | "门牌上的数字慢慢转——副本 N-051，准入倒计时 00:30。" |
| **H4** | 队友卧槽 | 队友/盟友被惊到 | "队友视角 + 三连追问" | "齐墨盯着账单：'你哪来的？什么时候去的？为什么我不知道？'" |
| **H5** | 真相一瞥 | 揭示部分真相（卷二后） | "锚点物件 + 残缺信息" | "档案残页上的签名只剩半个：S—。墨迹未干。" |
| **H6** | 危机降临 | 看似胜利时反派出手 | "胜利动作 + 系统警告" | "他关上门——系统提示：检测到 L 级权限正在拷贝你的日志。" |
| **H7** | 反转 | 主角发现自己被骗 | "主角自言自语 + 物件矛盾" | "他低头看手心。规则原文写的不是'通关'。是'活下来'。" |
| **H8** | 同盟确认 | 关键节点结盟 | "无对白 + 一个动作 + 一个物件交付" | "苏念把档案推过来，没说话。林觉接过去，也没说话。" |

### 抽签规则（按卷限定）

- 卷一：H1/H3/H4/H8 优先，禁用 H5/H7
- 卷二：H1/H2/H4/H5/H8，H5 限"一瞥"格式
- 卷三：8 选 1，但 H7 限 ≤ 1 次/5 章
- 卷四：H2/H5/H6/H7/H8 优先（压抑爆发）
- 卷五：H1/H2/H6/H7/H8 高频

## 二、装逼模板（B1-B6）

| 编号 | 类型 | 模板要点 | 示例 |
| --- | --- | --- | --- |
| **B1** | 一句话破规则 | 别人苦攻，主角一句话点透 | "他扫一眼公告：'触发对象写的是动作，不是结果。' 全场静了。" |
| **B2** | 反向规则 | 别人按规则走死，主角反向解 | "规则说'不能开门'。他没开门——他把门拆了。" |
| **B3** | 设计师降维 | 用职业本能看穿设计意图 | "这副本的难度曲线我半年前画过。出题人偷懒了。" |
| **B4** | 冷面打折 | 对高价情报随手砍价 | "三千碎片？" 他把卡推回去，"五百，含验证。" |
| **B5** | 沉默碾压 | 不解释，只用结果说话 | 林觉走进死亡触发区，三秒后走出来。身后规则文本熄灭。 |
| **B6** | 反客为主 | 反派以为掌控，主角递规则 | "你的访问权限是 L-3，"他说，"我刚帮你升到 L-0。" |

### 抽签规则

- 每章必有 ≥ 1 次装逼瞬间
- B1/B3 本色装逼，可常用
- B5 限沉默场景（通关/对峙）
- B6 限"对手摆架势"情境，卷三后解锁

## 三、打脸模板（S1-S4）

| 编号 | 类型 | 触发情境 | 三幕节拍 |
| --- | --- | --- | --- |
| **S1** | 看不起 → 真香 | 对手公开看不起新人 | 嘲讽 → 事实打脸 → 对手沉默/递台阶 |
| **S2** | 报价 → 反报价 | 谈判中被压价 | 开高价 → 揭穿货色 → 反求合作 |
| **S3** | 围攻 → 单破 | 多人围攻一人 | 摆阵 → 关键一问 → 阵法因漏洞解体 |
| **S4** | 嘴硬 → 系统反馈 | 反派宣告"已完成" | 话音落 → 系统/档案/物件呈现相反结果 |

### 抽签规则

- 卷一-二：S1/S2 高频
- 卷三-四：S3/S4 高频
- 任一打脸必须给被打脸者**≥ 1 句反应**（不能是工具人）

## 四、子情境骨架（D1-D5）

| 编号 | 类型 | 节拍 | 适用卷 |
| --- | --- | --- | --- |
| **D1** | 措辞陷阱 | 进入 → 读规则 → 主语模糊 → 错解死 → 重定义 → 过关 | 卷一 |
| **D2** | 触发顺序 | 进入 → N 条规则 → 误判顺序 → 队友死 → 主角倒推 → 过关 | 卷二 |

## 五、破局动作类型（A1-A8 / FatigueCheck 监控）

| 编号 | 动作 | 描述 |
| --- | --- | --- |
| **A1** | 措辞推理 | 拆解规则原文主语/谓语/触发对象 |
| **A2** | 触发顺序倒推 | 通过执行顺序漏洞过关 |
| **A3** | 反向激活 | 主动触发"禁止条件" |
| **A4** | 验证试探 | 低风险试错积累信息 |
| **A5** | 信息交换 | 与盟友/中间人/市场交易 |
| **A6** | 时间差 | 利用刷新/冷却/同步延迟 |
| **A7** | 身份伪装 | 利用权限/账号/称谓 |
| **A8** | 设计意图反推 | 看穿出题人意图后拒绝预设路径 |

### 抽签规则

- **同一类型连用 ≤ 2 章**（FatigueCheck 硬门禁）
- 卷一：A1/A4/A5
- 卷二：+ A2/A6
- 卷三：+ A3/A7
- 卷四：+ A8
- 卷五：全解锁，A8 为核心

## 六、组合使用示例（卷一第 3 章）

- 破局动作：A1（措辞推理）
- 装逼模板：B1（一句话破规则）
- 打脸模板：S1（看不起 → 真香）
- 子情境骨架：D1（措辞陷阱）
- 章末钩子：H4（队友卧槽）

→ AI 生成时：林觉用 A1 拆解规则主语，用 B1 一句话点破，副本老炮按 S1 走完三幕，章末用 H4 让老炮发出三连追问。
