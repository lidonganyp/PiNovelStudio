# 情节架构手册（Plot Architecture）

> 本文件是 `plot-architect` 的唯一知识库，合并原「情节架构 + 分卷弧线模式库」两份资料，已去重。
> 模式只提供"结构骨架"，不提供句式与场景；禁止把模式当成硬配额。

## 1. 倒推法

1. 先写"全书最后一章的形态"（主角在哪、世界变成什么样、读者记住了什么）。
2. 从终局倒推 3–5 个中间状态，每个状态对应一卷的出口。
3. 每卷的入口 = 上卷出口；出口 = 下卷入口，不允许断链。

## 2. 分卷四段式

```markdown
| 卷 | 进入状态 | 主要冲突 | 代价支付 | 出口状态 | 出场权重 |
|---|---|---|---|---|---|
```

**验收**：出口状态缺失 = 该卷未完成规划；"代价支付"写"无" = 该卷大概率无张力。

## 3. 分卷弧线模式库

| 弧型 | 段落序列 | 关键要求 |
|---|---|---|
| 复仇弧 | 失去 → 积蓄 → 第一次交锋 → 代价 → 收束 | 代价段必须伤及无辜，逼主角做选择 |
| 守护弧 | 失去 → 承担 → 被误解 → 证明 → 再次失去／守住 | 守护对象必须具体（一个人／一座城／一个承诺），不能是抽象"正义" |
| 揭秘弧 | 异常出现 → 收集线索（读者可参与）→ 假解释 → 真解释 → 后果 | 假解释必须"读者能理解为什么会有人这么想" |
| 成长弧 | 不自知 → 被羞辱 → 强行突破（代价）→ 失衡 → 重新校准 → 定型 | 突破后必须**失衡**，否则成长显得廉价 |

复仇弧分段出口：

| 段 | 功能 | 出口状态 |
|---|---|---|
| 失去 | 主角付出不可逆代价 | 目标确立 |
| 积蓄 | 获得手段，但被反制 | 手段有缺陷 |
| 第一次交锋 | 部分成功，暴露弱点 | 敌人升级 |
| 代价 | 复仇伤及无辜 | 主角面临选择 |
| 收束 | 完成复仇或放弃复仇 | 主角价值变化 |

**弧线组合检查**：

- 每卷只允许一条主弧 + 至多一条副弧。
- 主弧出口必须成为下卷入口。
- 连续两卷同型弧 → 读者疲劳预警。

**出口状态模板**：

```markdown
## 卷N 出口状态
- 主角位置：<社会身份/能力层级/地理>
- 主角认知：<他知道/不知道什么>
- 关系变化：<谁靠近/谁疏远/时间>
- 未解决：<必须留给下卷的问题>
```

## 4. 期待兑现曲线字段

```markdown
| 期待ID | 内容 | 埋设(卷/章) | 部分兑现 | 完全兑现 | 风险 |
|---|---|---|---|---|---|
| EXPECT-01 | 主角身世之谜 | 卷1/ch2 | 卷2/ch35 | 卷4/ch120 | 埋设过久易遗忘 |
```

**规则**：完全兑现前必须有至少一次"部分兑现"，否则读者会觉得突然。

## 5. 信息差矩阵

```markdown
| 反转ID | 谁知道 | 谁不知道 | 读者位置 | 信息差来源 |
|---|---|---|---|---|
```

**关键**：每个反转必须能回答"读者为什么没提前想到，但又觉得合理"——来源通常是"某章某事件提供了一条被忽略的线索"。

## 6. 节奏塌陷排查表

| 症状 | 判定 | 补偿手段（类型级） |
|---|---|---|
| 连续 5 章无冲突 | 塌陷 | 引入新对手 / 暴露旧代价 |
| 连续 3 章无新信息 | 塌陷 | 释放新线索 / 视角切换 |
| 连续解释性段落 >2 段 | 超载 | 把解释拆进事件 |
| 主角长期被动（>3 章） | 塌陷 | 给主角一次主动选择 |

**注意**：以上为诊断维度，不是硬配额；不得写成"每 3 章必须有一个爽点"的生产规则。

## 7. 与下游的交接

- 交给 `foreshadow-keeper`：全部 `EXPECT-*` 及其窗口。
- 交给 `chapter-intent-builder`：本卷功能卡 + 本章在卷内的位置。
- 交给 `reader-proxy`：期待兑现计划，供其核对兑现度。
