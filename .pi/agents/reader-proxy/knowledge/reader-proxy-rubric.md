# 读者视角评分手册（Reader Proxy Rubric）

> 本文件是 `reader-proxy` 的唯一知识库，合并原「读者视角评分 + 钩子与兑现模式目录」两份资料，已去重。

## 1. 五类弃书点定义

| 类型 | 定义 | 典型信号 |
|---|---|---|
| 信息密度骤降 | 连续段落无新信息 | 我跳过整段 |
| 情绪断层 | 上一段紧张，下一段突然闲聊 | 我的注意力掉了 |
| 主角长期被动 | 连续多章挨打无反击 | 我不想看他再倒霉 |
| 解释性段落过长 | 连续 2 段以上在讲设定 | 我记不住这些名词 |
| 新人物突袭 | 无铺垫出现新角色并占大量篇幅 | 我不关心他 |

## 2. 情绪四态标注规则

| 状态 | 判定 |
|---|---|
| 紧张 | 存在明确威胁或倒计时 |
| 期待 | 出现未兑现的承诺或悬念 |
| 松弛 | 无冲突的日常或抒情 |
| 失望 | 承诺落空 / 期待被浪费 |

**曲线规则**：连续 3 段以上"失望 + 松弛"即高风险区。

## 3. 期待兑现表与兑现节奏

```markdown
| 期待ID | 本章兑现度(0-3) | 证据定位 | 是否落空 |
|---|---|---|---|
```

0 = 未提及，1 = 提及，2 = 部分兑现，3 = 完全兑现。

跨章节奏自检：

```markdown
| 章 | 埋下期待 | 部分兑现 | 完全兑现 | 落空 |
|---|---|---|---|---|
```

**规则**：连续 5 章只埋不兑 → 读者疲劳；同一章同时完全兑现 3 条以上 → 爽点通胀。

## 4. 章末钩子五型与强弱判据

| 类型 | 结构 | 强钩子判定 |
|---|---|---|
| 新问题型 | 出现一个具体的新疑问 | 读者能说出"我想知道 X 是谁/为什么" |
| 不可逆选择型 | 主角做出无法撤回的决定 | 选择带来可见代价 |
| 对手升级型 | 对手获得可见优势 | 优势具体（拿到了什么） |
| 时限压迫型 | 出现倒计时 | 有明确期限 |
| 关系裂缝型 | 信任出现裂痕 | 裂痕有具体触发事件 |

**弱钩子特征**："接下来会发生什么呢""他暗下决心""命运的齿轮开始转动""决定继续努力"、笼统的威胁。

## 5. 爽点类型（诊断维度，不是配额）

| 类型 | 读者获得 | 常见误用 |
|---|---|---|
| 能力兑现 | 主角实力被验证 | 无代价的瞬发碾压 |
| 智谋兑现 | 主角先于对手想到 | 对手降智 |
| 身份揭示 | 主角被重新评价 | 无铺垫的突然身份 |
| 关系确认 | 关系推进被承认 | 强行撒糖 |
| 代价偿还 | 之前的付出被回报 | 回报来得太迟 |

## 6. 读者画像表（按类型）

| 类型 | 读者最在意 | 最容易弃 |
|---|---|---|
| 玄幻升级 | 成长可感知、爽点密度 | 憋屈超过 3 章 |
| 悬疑推理 | 线索公平、推理可参与 | 关键线索不给读者 |
| 言情 | 关系推进、情绪共鸣 | 误会拖太久 |
| 都市现实 | 逻辑自洽、代入感 | 设定离谱 |
| 历史 | 细节可信、时代感 | 现代词穿越 |

## 7. 弃书点与钩子的关系

- 弃书点通常出现在"钩子未兑现且无新钩子"的章节。
- 修复优先级：先给**新钩子**，再考虑兑现旧钩子。

## 8. 输出纪律

- 一律用第一人称阅读反应举证："我读到第 X 段时想跳读""我在第 41 段想关掉页面"。
- 群体判断必须标 `[推测]`；无来源数据一律删除。
- 禁止给"评分/建议重写"这类裁决性结论。
- 首行必须有："本报告是读者体验诊断，不构成质量裁决。"
