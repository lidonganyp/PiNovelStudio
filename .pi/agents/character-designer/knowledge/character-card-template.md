# 人物卡与关系网手册（Character Card & Relationship Network）

> 本文件是 `character-designer` 的唯一知识库，合并原「人物卡模板与 OOC 判定 + 关系网与群像」两份资料，已去重。

## 1. 七栏人物卡

```markdown
| 栏目 | 填写要求 |
|---|---|
| 身份/职能 | 在故事中负责推动/阻碍/镜像/见证/代价中的哪一种 |
| 欲望 | 他主动想要什么（可观察的目标） |
| 恐惧 | 他害怕失去什么（决定他在压力下的选择） |
| 底线 | 他绝不会做的一件事（防 OOC 的核心锚） |
| 能力边界 | 能做到什么，做不到什么 |
| 语言习惯 | 句长偏好 / 称呼习惯 / 口头禅 / 绝不会说的词 |
| 身体记号 | 疤、残疾、习惯动作（供连续性核对） |
```

## 2. 动机链写法

```markdown
- M-01：<过去事件> → <由此形成的信念> → <当前章节的选择>
```

**要求**：至少两条链，且必须能解释"为什么现在做，而不是早三章做"。

## 3. 功能配比（防工具人）

| 功能 | 至少 1 名 | 典型问题 |
|---|---|---|
| 推动者 | 主角 / 导师 | 只推动不受伤 |
| 阻碍者 | 反派 / 体制 | 只坏不解释 |
| 镜像者 | 同类不同选择者 | 与主角无差异 |
| 见证者 | 旁观 / 记录者 | 只当传声筒 |
| 代价承担者 | 被牵连者 | 死了也没人记得 |

## 4. 关系矩阵

```markdown
| A | B | 关系 | 强度(1-5) | 张力来源 | 翻转条件 |
|---|---|---|---|---|---|
| 林默 | 苏雨 | 盟友 | 4 | 她隐瞒了身世 | 她坦白或被揭穿 |
| 林默 | 陈九 | 敌对 | 5 | 陈九杀其师 | 陈九暴露苦衷 |
```

**判定**：强度全为 4–5 = 群像扁平；全部无翻转条件 = 关系静止。

## 5. 关系演化表（跨卷）

```markdown
| 关系对 | 卷1 | 卷2 | 卷3 | 变化触发事件 |
|---|---|---|---|---|
```

**规则**：每对核心关系在全书至少经历一次翻转，否则读者感受不到"关系在推进"。

## 6. 声音区分练习（对每个主要角色填）

| 角色 | 句长偏好 | 称呼主角 | 口头禅(≤5字) | 绝不会说的词 |
|---|---|---|---|---|
| 林默 | 短促 | "苏雨" | "走吧" | 书面成语 |
| 陈九 | 长句缠绕 | "小崽子" | "有意思" | 道歉类词 |

**检验**：把四行台词去掉说话人，能否凭用词认出是谁。认不出 = 声音未区分。

**词表口径**（供文风校准师引用）：

| 维度 | 取值示例 |
|---|---|
| 句长 | 短促 / 长短交替 / 长句缠绕 |
| 称呼 | 直呼其名 / 称号 / 贬称 / "你" |
| 口头禅 | 一句即可，不超过 5 字 |
| 绝不会说的词 | 与其阶层/时代不符的词（如古代人不说"系统"） |

## 7. 群像出场节奏

- 单章新增主要角色 ≤1 名；配角可 2 名但必须有既有角色引荐。
- 新角色首次登场必须给"一个可记住的动作"而非一段履历。
- 连续 3 章只有主角说话的段落 → 群像失衡预警。

## 8. OOC 判定表

```markdown
| OOC-ID | 角色 | 绝不做的事 | 判定方式 |
|---|---|---|---|
| OOC-01 | 林默 | 不会为自保出卖同伴 | 出现"主动交出同伴位置"即判定 OOC |
```

**判定规则**：必须能在正文中定位到具体行为；不可判定的（"不会变坏"）不收。

## 9. 与 canon 的交互

- 角色能力边界必须引用 `FACT-*`；冲突时以 canon 为准。
- 若剧情需要角色突破边界，先让 `world-builder` 补"升级路径"事实，再改角色卡。
