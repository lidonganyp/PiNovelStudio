# 总策划工作手册（Director Playbook）

> 本文件是 `novel-director` 的唯一知识库，合并原「立项五元组 + 赛道定位矩阵」两份资料，已去重。

## 1. 立项：定位四维 + 五元组

| 维度 | 必须回答 | 判定标准 |
|---|---|---|
| 类型 / 子类型 | 平台可识别的分类词，不自造 | 能一句话说出同类作品叫什么 |
| 读者 | 谁在什么场景读 | 能说出替代娱乐（短视频/游戏）是什么 |
| 承诺 | 读者付时间换什么 | 承诺可被单章验证 |
| 差异 | 与同类前三名的可观察区别 | 能写成"别人不会这样写" |
| 核心冲突 | "想要 X，但 Y 不允许" | 一句话可判定 |
| 三条绝不做 | 明确排除，防跑偏 | 每条可判定 |

**反例**：类型写"新颖独特的混合类型"、卖点写"更加精彩"、绝不做写"不要写得太差"——均不可观察、不可验证。

## 2. 类型 × 承诺速查

| 类型 | 核心承诺 | 首章必须给到 | 最常见跑偏 |
|---|---|---|---|
| 玄幻升级 | 成长可感知 | 一次明确的实力/地位变化 | 前期憋屈超过 3 章 |
| 悬疑推理 | 线索公平可参与 | 一个可被读者记住的疑点 | 关键线索只给主角 |
| 言情 | 关系推进与情绪共鸣 | 一次有张力的互动 | 误会拖 5 章以上 |
| 都市现实 | 逻辑自洽与代入 | 一个贴近生活的困境 | 设定玄幻化 |
| 历史 | 时代细节可信 | 一处精准的时代细节 | 现代词汇穿越 |
| 无限流/系统 | 规则清晰可玩 | 一条明确规则 + 一次奖励 | 规则随手改 |

## 3. 差异化卖点写法

```
别人做 X（同类默认做法）
我做 Y（可观察差异）
代价是 Z（作者要接受的损失）
```

## 4. 阶段验收清单（每阶段只验收"可被下游消费"）

| 阶段 | 产物 | 验收问题 |
|---|---|---|
| 立项 | 定位四维 + 五元组 | 作者是否签字确认？三条"绝不做"是否可判定？ |
| 设定 | canon 事实 + 术语表 | 每条事实是否可判定？`worldKeyTerms` 是否覆盖别名？ |
| 人物 | 人物卡 + OOC 清单 | 是否有 `characterId` 且与 `config.json` 对齐？ |
| 结构 | 卷功能卡 + 期待曲线 | 每卷是否有出口状态？`EXPECT-*` 是否有埋设与兑现窗口？ |
| 伏笔 | 台账 | 是否有埋设定位？是否与 PromiseLedger 对账？ |
| 写前 | 章节契约 | `status` 是否 `ready`？硬事实是否只引用已有 ID？ |
| 写后 | 三份诊断 | 是否都有定位证据？是否都声明"不构成裁决"？ |
| 交付 | 质检报告 | 结论是否二值化？是否原样引用工具字段？ |

```markdown
| 风险ID | 描述 | 责任专家 | 触发条件 | 兜底动作 | 状态 |
|---|---|---|---|---|---|
| RISK-01 | 复苏之眼设定与第3章能力展示冲突 | world-builder | 第5章写到能力升级 | 回 canon 补"代价升级"条目 | open |

| RISK-04 | 卖点不可持续：差异只够写 20 章 | plot-architect | 卷1 末 | 设计卖点升级路径 | open |
```

## 6. 常见返工原因（按出现频率排序）

1. **设定未落 canon**：口头上定了规则，没写进 `WORLDBUILDING-CANON.md`，导致后续章节自相矛盾。
2. **意图过载**：一章塞 4 条以上意图，正文模型只能各写一点，结果全浅。
3. **承诺只埋不收**：`plot-architect` 埋了期待，`foreshadow-keeper` 台账没登记。
4. **诊断与裁决混淆**：把 `reader-proxy` 的"我想弃书"当成"必须重写"。
5. **绕过工具**：用 AI 自己写的段落充当章节正文（项目铁律禁止）。
