# 文风诊断手册（Style Diagnosis）

> 本文件是 `style-guardian` 的唯一知识库，合并原「文风诊断 + 风格指纹字段与档案对接」两份资料，已去重。

## 1. 定性风格维度（只写"倾向"，不写数值；附档案证据）

| 维度（档案字段） | 描述示例 | 证据（原文例 ≤20 字） |
|---|---|---|
| 句式倾向 | 短句推进为主，长句集中在情绪堆积处 | "他没说话。风停了。" |
| 词汇层级 | 口语化为主，避免书面成语堆叠 | "他心里发毛" |
| 比喻倾向 | 比喻取自日常经验，密度随场景强度浮动，不做硬性限量 | "像湿绳子一样勒住" |
| 对白节奏 | 对白短促、经常打断，不说完就换人 | "你听我说——" |
| 叙述视角 | 紧贴主角第三人称，不做全知评论 | "他能听见自己心跳" |
| 标点偏好 | 少用感叹号，破折号用于停顿 | — |
| 情绪表达 | 用动作代替直陈 | "他把杯子放回桌上，很轻" |
| 禁忌表达 | 不用"仿佛世界安静了" | — |

## 2. AI 腔高频信号

- 情感直陈："他的心中涌起一股难以言喻的…"
- 空泛比喻："仿佛整个世界都安静了"
- 过度排比："不是…而是…不是…而是…"（连续出现）
- 解释性旁白："他知道，这一刻，他的人生将彻底改变。"
- 对称句滥用："一边…一边…"每段都有

## 3. 翻译腔高频信号

- "一个…的存在""对于…而言""在…的同时"
- 冗余定语："他那双深邃的、仿佛能看透一切的眼睛"
- 被动句密集："他被认为是一个…的人"
- 长定语套嵌导致读者要回读

## 4. 定位写法（必须可定位）

```
第N段#<片段前6字>
```

禁止：整体偏口语 / 后半段有点飘 / 某些地方像 AI。

## 5. 编辑意图三原则（不产出替代正文）

1. **只给方向**：说明"往哪个方向调整"（如"把直陈情绪改为可观察的身体反应"），不写替代句子、不给"改前/改后"对照。
2. **保信息**：调整不得删减原文信息量（谁做了什么、结果如何）；需要删减信息时必须标"需作者判断"。
3. **禁新增**：不得新增事实、人物、设定、比喻来源；越界的一律降级为"需作者判断"。

改写执行权归正文模型与作者；本专家只交付定位、证据与意图。

## 6. 常见误判

| 误判 | 说明 |
|---|---|
| 把"作者特色重复"当成 AI 腔 | 先查风格档案是否已登记该特征 |
| 把"短句多"当成节奏差 | 短句是风格选择，不是问题 |
| 把所有长句当翻译腔 | 只有套嵌过长、需要回读的才算 |
| 用统计当判决 | 句长分布、对白比例只能做证据 |

## 7. 与 workspace 风格档案的闭环

- 生产链路读取 `workspaces/{id}/` 下的作者风格档案，**只消费定性指导**。
- 若档案缺失或类型不匹配（只有统计指纹而无定性指导），风格优化阶段会被门禁阻断（`gate=style_optimization`）。
- 闭环三步：① 从作者认可的正文提取 `ST-*` 条目 → ② 作者确认 → ③ 才写入风格档案。未确认条目只能作为"候选观察"，不得进入生产输入。
- 本专家负责"把定性观察整理成条目"，但**不直接写 raw prompt**。

## 8. 跨章一致性检查

- 同一作者档案下，连续 3 章的定性条目应稳定；出现新条目需作者确认。
- 若两章之间风格条目冲突（如"少用感叹号" vs 连续感叹号），标 `ST-CONFLICT` 交作者裁决。

## 9. 禁止事项

- ⛔ 不把统计值（句长百分位、对白比例）写成硬约束。
- ⛔ 不把"AI 腔词表"当禁用词清单强加给正文模型。
- ⛔ 不用风格诊断结果直接替换已交付正文。

## 10. 输出纪律

- 报告首行声明："本报告为诊断，不构成正文替换。"
- 每条建议必须能指到 `ST-*` 条目与 `SD-*` 问题 ID。
